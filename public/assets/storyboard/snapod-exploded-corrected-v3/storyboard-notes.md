# SNAPOD-S 爆炸图分镜修正版 v3

## 核对结论

- 原红框并不能证明零件应被删除。说明书结构仍需要左右侧板、后玻璃和四根立柱扣盖。
- 红框中的主要问题是多个零件沿同一投影线重叠，导致玻璃、侧板和扣盖看起来重复或黏连。
- 灰色吸音功能板、桌板和高脚凳未列入说明书的八项主体零件，本版将其作为固定内部功能模块保留，不参与外壳数量计算。

## 六帧节奏

1. 完整产品。
2. 顶板抬升，立柱扣盖开始向外移动，主体侧板仍保持装配状态。
3. 门、后玻璃、两块侧板和四根扣盖进入中等爆炸距离。
4. 所有零件继续拉开，保持独立轮廓与可见间距。
5. 接近最大爆炸状态。
6. 最大爆炸状态，两块绿色侧板分别位于最外侧，门、后玻璃、四根扣盖和中央功能模块互不遮挡。
